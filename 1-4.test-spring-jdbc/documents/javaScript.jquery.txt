基本はキャメルケース

厳密等価演算子でデータ型を比較できる
3 === 3 整数同士比較
3 === '3' 整数と文字列なのでfalse
3 !== 3 false
※ == もあるが値しか判定しないので 3 == '3' はtrueになる

}

mainメソッドはない

いったんはこれだけ覚えればいいのかも

関数式
関数と違って宣言より前で呼び出すとエラーになる
関数の名前はつけない

アロー関数式
functionの代わりに =>で書ける

スコープ
varを使用して関数の外で宣言した変数はグローバルスコープになり、
同じHTMLで読み込まれている別のjsファイルからも呼び出すことができる

関数の中で宣言したらその関数の中でしか使えない
javascriptで「var」を使うとifの内側で定義した変数に対してもアクセスできてしまう
letを使ったらjavaと同じ挙動になる

Strictモード
'use strict';

〇varは使わないようにする
let:変数宣言で使う
const:定数宣言で使う

jQuery
基本形
$('セレクタ').関数();

$('セレクタ').on('イベント名', function(){
	$('セレクタ').関数();
});

セレクタ:HTMLの要素
例:$('div') HTML内のすべてのdivタグ
$('#aaa') idがaaaのタグ
$('.bbb') classがbbbのタグ
$('div.ccc') divタグでクラスがccc
